**晚钟 · EVENING BELL**

根据修订后的《情感陪伴自律 APP 产品需求文档》实现的本地网页应用，兼顾电脑和手机布局。所有源代码、测试和启动说明均在此目录。当前版本使用浏览器保存个人数据，服务端负责可选的大模型请求。

**快速运行**

Windows 上双击本目录的 `启动.cmd`。保持启动窗口开启，在浏览器访问窗口显示的 Local 地址，通常为 `http://localhost:3000`。端口被占用时以实际输出为准。启动文件支持系统 Node.js，也会尝试当前 Codex 环境自带的 Node.js。

在新电脑上，需要 Node.js 22.13 及以上版本，建议 Node.js 24；使用 pnpm 安装依赖：

```sh
cd Code
pnpm install
pnpm dev
```

当前工作区已安装依赖。可以直接运行：

```sh
node scripts/start.mjs
```

生产构建及本地生产运行：

```sh
pnpm build
pnpm start
```

`pnpm start` 使用 Wrangler 在本机运行构建后的 Worker，不会发布到公网。此项目尚未部署，也没有创建远程数据库。

**第一次体验**

1. 点击“新建计划”，填写目标、完成标准和可选截止时间。粘贴已有任务或生成拆分草稿，检查子任务、估时、依赖及固定时段后保存。
2. 也可以点击“试用示例目标”，加入作品集和阅读的示例。示例不包含虚构的完成记录。
3. 点击“我到家了，安排今晚”，确认今天的起止时间、精力和固定事务。预览可编辑时间、移除任务、锁定时间块；采纳后才写入当前安排。
4. 到安排的时段后点击“开始专注”。如果需要立即体验，可在报到时把开始时间设为当前时间，并在设置中把准备时间设为 0。
5. 到时或提前结束后，明确选择“任务完成”“还需继续”或“今天先到这里”。未完成任务保留剩余工作量；今天停止的任务退出当天后续安排。
6. 临时加班可重新报到，也可以输入“晚半小时开始”“很累，只想做半小时”“今天休息”，检查新草稿再采纳。
7. 在“专注记录”查看真实投入和每日复盘；在“偏好设置”设置通常可用时段、番茄时长、提醒和陪伴。

演示时可在偏好设置开启“10 秒演示番茄”并保存。演示计时会明确标记，并排除在正式专注统计之外；演示模式允许忽略现实起止时段，但仍检查真实任务依赖。关闭后恢复正常计时。

**已实现的功能**

- 目标与子任务创建、编辑、删除、合并、优先级、截止日期、完成标准、剩余工时、精力要求、依赖及不可拆分约束。
- 依据当天实际可用时间进行本地调度，预留准备、休息及缓冲；多个目标共用时间预算；截止日前容量不足或信息未知时明确提示。
- 固定事务、固定任务、跨午夜时段、锁定、重排预览、采纳、撤销及今日延后。不可行的固定任务会解释原因，锁定冲突需要用户解决。
- 与任务关联的番茄钟、暂停、继续、提前结束、切换、短休息和每四轮长休息。以时间戳恢复，不靠计数器累减；结算具有会话去重。
- 任务开始前再次检查前置任务真实完成状态；专注时间和完成状态分开记录。
- 当前设备数据持久保存、跨标签页同步（支持 Web Locks 的浏览器采用原子写入）、心情删除、数据导出及清除。
- 温和陪伴、本地状态指令解析、可选 AI 拆任务和陪伴对话。
- 助手名为“小晚”。全局右上角可新建计划和查看通知，侧栏包含日历、每日习惯与反馈入口。
- 截止日历按日期标出目标数量，点击查看具体截止时间及完成状态，并可编辑原计划。
- 每日习惯无需截止日期，可设置重复星期、时长、精力、优先级和是否分次完成；支持暂停、编辑、删除和当日完成。排程按当天生成实例，保留历史，次日按设定时长重新开始，不积压昨日习惯；跨午夜沿用前一晚的实例。
- 通知中心保存任务、番茄钟和临近截止的提醒，支持未读数量、全部已读与跳转；修改截止时间或完成目标后更新截止提醒。
- 反馈可在当前设备保存和导出，尚未配置接收反馈的服务器，因此不会自动发送给开发者。
- 应用内提醒、可选系统通知和提示音、任务提前提醒、稍后提醒及提醒时段控制。
- PWA 清单及 Service Worker；已访问的生产资源可以缓存用于断网后恢复。首次访问需要正常加载资源。

**配置真正的大模型服务（可选）**

不配置密钥时，所有排程、计时、记录和本地拆分功能仍可使用，界面显示“本地助手”。本地拆分是规则草稿，不伪装成大模型生成。

复制 `.dev.vars.example` 为 `.dev.vars`，填写你选择的服务商信息并重启：

```dotenv
AI_API_KEY="你的密钥"
AI_BASE_URL="https://你的服务地址/v1"
AI_MODEL="模型名称"
```

服务需兼容 `POST /chat/completions`，拆分与排程排序请求使用 JSON 对象输出。`AI_BASE_URL` 填服务根地址，不包含 `/chat/completions`。服务端会校验模型输出及依赖索引，并设置超时。密钥不进入浏览器代码，`.dev.vars` 和 `.env` 已加入忽略规则。

配置 AI 后，用户主动请求拆分、生成今晚安排或陪伴对话时会调用该服务。拆分发送目标、完成标准及粘贴的主计划；排程发送当天候选任务和习惯的名称、剩余时长、精力、优先级、依赖、目标截止时间和报到信息；陪伴发送输入文字、当前目标、任务状态、习惯及报到信息。小晚提供任务与习惯的排序理由，固定事务、依赖、时间边界与休息仍由本地调度器处理，预览采纳后才保存。模型异常或返回非法任务 ID 时，排程自动回退本地规则并在预览说明中标明。没有真实服务密钥时，不能验证供应商连通性及其具体模型兼容性。

```text
app/                         页面入口、样式、布局
  api/agent/route.ts         可选 AI 服务端接口
components/planner/          应用页面、目标编辑、复盘、设置
```

技术基础：React 19、TypeScript、Vinext/Vite、Tailwind、Base UI/Shadcn，运行环境为本地 Cloudflare Worker。`pnpm-lock.yaml` 固定依赖；`pnpm-workspace.yaml` 仅允许已有 esbuild、sharp、workerd 运行必需安装脚本。

**检查代码**

```sh
pnpm test
pnpm typecheck
pnpm lint
pnpm build
# 应用正在运行且未配置真实模型时：
node scripts/smoke.mjs
```

Lint 检查应用代码。日历组件补接日期按钮的焦点引用，以支持键盘切换日期。HTTP 冒烟默认访问 localhost:3000，可通过 `SMOKE_URL` 指定实际本地端口。

**使用边界**

这是可本地运行的网页版本，没有打包 Android APK 或 iOS 安装包，也没有账号和跨设备云同步。不同浏览器、域名或端口分别保存数据。生产缓存需要先联网打开一次；网页关闭、系统休眠或浏览器限制后台时，无法保证准时系统通知，但重新打开后会恢复正确计时并避免重复记账。界面设置中也显示这一限制。

本次验证以自动化业务测试、类型检查、应用源码静态检查、生产构建和 HTTP/API 检查为依据；没有进行真机锁屏通知或完整浏览器交互验收。WebMCP 采用可用性检测，提供读取计划和生成预览的工具；当前未在支持该接口的浏览器中验证，不影响普通页面使用。

原始修订需求保存在 `docs/需求文档.md`，对应的验收说明见 `docs/验收说明.md`。
