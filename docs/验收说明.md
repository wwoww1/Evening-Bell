**晚钟｜实现与验证记录**

依据：同目录 `需求文档.md`，为用户修改后的需求副本。实现形态为本地网页应用，界面适配手机和电脑；原生手机安装包未包含在本次交付中。

| 需求 | 实现位置 | 验证依据 |
|---|---|---|
| A1 主计划与可编辑子任务 | `goal-editor.tsx`、`agent.ts`、`api/agent/route.ts` | 本地拆分、模型结构校验单元测试；接口创建草稿及无效输入检查 |
| A2 可用时段、休息与缓冲 | `scheduler.ts` | 90 分钟完整排程、零时间及不重叠测试 |
| A3 多目标、依赖及固定安排 | `scheduler.ts`、`actions.ts` | 共享容量、依赖、自依赖/循环、固定事务、固定任务前置及不可拆分测试 |
| A4 重排保留与预览 | `scheduler.ts`、`planner-app.tsx` | 锁定冲突时不覆盖原计划、保留已完成和锁定块；界面提供预览、采纳和撤销 |
| A5 工期不足与信息未知 | `capacityRisks()` | 两目标共享 120 分钟、需 180 分钟，报告 60 分钟缺口；未来未知返回未知容量 |
| A6 实际专注与完成分离 | `timer.ts`、`actions.ts` | 暂停、提前结束、迟到恢复、重复结算、休息排除及任务真实依赖测试 |
| A7 后台恢复与权限降级 | `timer.ts`、设置及主界面 | 时间戳恢复单元测试；系统通知使用权限检测，拒绝后保留应用内提示。真机锁屏通知未验证 |
| A8 疲惫或零时间 | `parseCheckin()`、调度及陪伴界面 | 疲惫指令和零时间测试；允许调整窗口及今天停止某任务 |
| A9 离线与 Agent 失败 | 本地调度、`store.ts`、`sw.js`、Agent 接口 | AI 失败不会写入主计划；本地功能不依赖模型服务；缓存及离线浏览器行为需实际设备补充验收 |
| A10 重开应用及删除 | `store.ts`、设置、记录页面 | 浏览器 localStorage 持久化、会话去重；提供导出、删除心情、删除复盘和清除全部数据 |

已执行：45 项业务回归测试、TypeScript 类型检查、应用源码 lint、生产构建，以及页面/API/PWA 资源 HTTP 冒烟检查。原有 29 项继续通过；新增 16 项覆盖每日习惯实例去重、次日恢复、暂停和删除保留历史、旧预览与当日跳过冲突、跨午夜归属、习惯占用期限容量、模型排序输出校验、日历聚合、通知去重和旧版数据迁移。

本轮界面修改：应用更名“晚钟”、助手名“小晚”；删除左下角标语和首页陪伴标语卡；左下角提供本机反馈保存/导出；侧栏增加日历与每日习惯；右上角提供通知中心和全局新建计划。每日习惯没有 deadline，会在生成今晚预览时纳入候选任务；配置模型后调用小晚排序，无配置或服务失败时使用本地调度。

没有用户提供的真实模型密钥，因此没有向真实模型服务发请求。服务器接口已实现，并验证了无密钥模式、无效请求处理和来源检查；配置方法见 README。

浏览器视觉检查、完整点击流程、手机锁屏提醒和 WebMCP 运行时验证未执行。交付不将这些项目标记为已通过。网页关闭或后台暂停时的准时提醒限制已写入设置界面及 README。
